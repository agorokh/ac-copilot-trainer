## Implementation under review

One human curriculum stage/canonical corner locks across attempts. Human PB/progression/
reference qualification remains at the normal consumer boundary. Practice refuses
legacy-unknown/assisted or imported provenance. Existing alien-line routing remains bounded
to apex speed; it does not supply brake/trail/throttle technique. Frozen drill anchors
and targets cannot drift under driver-lap calibration. The normal unlocked coach remains
the comparator before the block; no profile promotion follows a practice result.

Canonical Lua geometry may fall back only when the existing corner catalog is genuinely
empty. The fallback samples authored CSP boundary midpoints, derives deterministic
curvature intervals, and publishes through the same authoritative catalog. Malformed named
catalogs fail closed; Python naming guards remain intact. Derived geometry is not a racing
line or technique reference. The installed CSP SDK was checked for boundary/wheel APIs.

Native telemetry carries archive session UUID/all-boundary ordinal with ambiguous transition
frames omitted. Optional `wheelsOutside` appends after the existing 100 trace columns; unknown
is -1, never zero. The full-lap summary is accumulated before archive downsampling. Native
finish/start continuity and uninterrupted recording are required for `complete=true`.

Actual voice dispatches are joined by local monotonic intervals to completed native laps.
SAVE is distinct from instruction; unknown semantics/durations cannot certify uncued laps.
Retention guards current/queued/deferred instructions; cancellation diagnostics invalidate
full-clip proof without rewriting dispatch history or emitting new speech. Voice evidence
readiness requires both listeners, the installed guard and zero observed evidence errors.
Backend return/current-cleared state does not prove acoustic silence.

Game Point owns the default-off Practice drill checkbox, setting/env override and advisory
status row. An active/adopted sidecar is never stopped or reconfigured by that toggle.
Public health exposes only operational fields; private targets, IDs, metrics and traces
remain behind the existing token-authenticated route. No credential value is logged.
