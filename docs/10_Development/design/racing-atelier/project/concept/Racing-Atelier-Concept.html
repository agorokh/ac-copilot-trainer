An instrument cluster.
Not a magazine. Not a game.

This corrects course. The eye at speed reads in periphery — it catches size, colour fields and lit blocks, never an italic or a hairline tick. So the racing register is built from the cockpit out: bold condensed numerals, chunky segmented indicators (shift-light logic), full colour fields for state, maximum contrast. It inherits from Atelier the things that travel — an authored token system, ruthless restraint, a named lexicon, instrument rigor — and none of the things that don't: the serif, the italics, the paper.

What it takes from Atelier — and what it refuses

keep

The discipline

One source-of-truth token file. Colour spent only on meaning. A named lexicon (corner, reference, zone, delta). Calm reframed as glanceable: one action loud, everything else quiet.

refuse

The dress

No serif, no italics, no hairline measures, no lowercase prose at the wheel. Those read as editorial calm — fatal on a dash. Legibility outranks taste here.

forge

The instrument

Shift-light segment bars, thick delta blocks, big tabular numerals, machined corner brackets, hazard fields. The vocabulary of the garage and the data bay, not the studio floor.

One command, periphery-caught

BRAKE + arrow in a hazard-red block, 66px. The eye flags it before it reads — colour and mass, not a word.

02

Distance is a count of blocks

Shift-light segments fill toward the red zone — you read how close as quantity of lit bars, plus one huge 86 m. No thin slider to decode.

03

Delta is mass + a big number

A thick block grows right of centre = too fast. The +14 is 44px. Direction and amount land in one glance.

04

Everything else is demoted hard

Corner, gear, speed, last-lap loss — small mono at the edges. The frame carries one decision, sized to matter.
