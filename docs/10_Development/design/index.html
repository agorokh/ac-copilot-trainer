How to extend this package

These screens are the seed set. The remaining surfaces from the written brief — Pocket Technician, Setup Exchange, Settings/Diagnostics, Voice/Haptics status, and the in-game CSP HUD — follow the same tokens and component patterns. Keep each change in the surface that owns it (LVGL firmware, Tkinter launcher, or CSP Lua HUD) and update both this file and 15_Claude_Design_UI_Package.md when a new screen or status row lands.
