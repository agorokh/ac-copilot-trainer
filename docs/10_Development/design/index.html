How to extend this package

This now covers the launcher (2 states), all three ESP32 app screens, diagnostics, voice/haptics status, and the in-game HUD. When a new screen, visible state, or status row lands, add it here and update 15_Claude_Design_UI_Package.md. Keep each change in the surface that owns it: LVGL firmware (firmware/screen/src/ui/), the Tkinter launcher (tools/rig_launcher/), or the CSP Lua HUD (src/ac_copilot_trainer/).
